# Ai-Achievements (Зал Славы)

Однофайловое веб-приложение для хранения и просмотра личных ИИ-ачивок в виде 3D-созвездия или сетки карточек.

Демо: https://zhitnikov.github.io/Ai-Achievements/

## Что умеет

- 3D-созвездие на Three.js: карточки сгруппированы по темам и соединены линиями, камеру можно вращать, приближать и кликать по узлам для просмотра описания.
- Сетка карточек: альтернативный режим просмотра с группировкой по категориям и 3D-наклоном при наведении.
- Фильтрация: переключение между темами и подсчет количества ачивок.
- Управление списком: добавление, редактирование и удаление карточек, сброс к исходному набору. Все правки сохраняются в `localStorage`.
- Экспорт и импорт JSON: выгрузка текущего списка в буфер обмена или файл `achievements.json` и загрузка обратно.

## Стек

Весь проект лежит в одном файле `index.html` без сборщиков и бэкенда:
- HTML / Vanilla JS
- Three.js (r128) + OrbitControls
- Tailwind CSS (CDN)
